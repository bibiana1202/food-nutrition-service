# 원본 데이터와 API 필드 매핑

과제에 연결된 [식품영양성분 엑셀](https://docs.google.com/spreadsheets/u/0/d/1IUU_wZLrPWO_h5GsDvfeYUHxau4pQDZo/edit)을 `data/foods.xlsx`로 보관한다. Google Sheets의 XLSX 내보내기로 2026-09-08에 내려받았다.

실제 파일에는 머리글을 제외한 **7,683개 행**, **100개 열**이 있다. 과제 소개의 90,105건은 전체 DB 설명이며, 이번에 제공된 음식 파일의 행 수와 다르다. `식품코드`는 이 파일에서 모두 유일하다.

| API 필드 | 엑셀 열 | 처리 |
| --- | --- | --- |
| id | 없음 | DB가 생성하는 식별자. 원본 NO와 분리 |
| food_cd | 식품코드 | 공백 제거, 대문자 정규화, 유일 키 |
| group_name | 식품대분류 | 구이류·국류 등의 분류. 모든 행이 음식인 DB군보다 유용한 분류 선택 |
| food_name | 식품명 | 앞뒤 공백 제거 |
| research_year | 연도 | 정수 |
| maker_name | 지역 / 제조사 | 앞뒤 공백 제거 |
| ref_name | 성분표출처 | 자료명. 발행기관과 구별 |
| source_notes | 일부 영양성분 셀의 한정 표현 | 예: `protein: 1g 미만`. 확정 수치를 만들지 않고 원래 표현 보존 |
| serving_size | 1회제공량 | 숫자 |
| serving_unit | 내용량_단위 | g 또는 mL. 단위 손실을 막기 위해 요구 항목에 추가 |
| calorie | 에너지(㎉) | kcal |
| carbohydrate | 탄수화물(g) | g |
| protein | 단백질(g) | g |
| fat | 지방(g) | g |
| sugars | 총당류(g) | g |
| sodium | 나트륨(㎎) | mg |
| cholesterol | 콜레스테롤(㎎) | mg |
| saturated_fatty_acids | 총 포화 지방산(g) | g |
| trans_fat | 트랜스 지방산(g) | g |

영양성분은 원본 값을 그대로 보존하며 100g 기준으로 임의 환산하지 않는다. `-`, 빈 셀 등 결측값은 0과 구별하여 `null`로 저장한다.

원본에는 `1g 미만` 표현이 총당류 12개, 단백질 3개, 탄수화물 1개 셀에 있다. 해당 숫자 필드는 `null`로 적재하고 `source_notes`에 필드명과 원문을 보존한다. 관리자 상세 화면과 API 응답에서 이 참고 내용을 확인할 수 있다.

빈 문자열, `-`, `N/A`, `NA`, `NULL`은 결측으로 처리한다. 숫자는 유한한 0 이상의 값만 허용하고 `1,234.5` 같은 천 단위 구분은 제거한다. `1,2`, `12mg`, 음수, 잘못된 연도, 필수 코드/이름 누락은 파일의 시트 번호와 행 번호를 포함한 오류로 중단한다. 숫자형은 MariaDB REAL/JavaScript number이므로 십진수의 이진 표현 오차는 가능하다. 금액 계산에 사용하는 고정소수점 정밀도를 보장하는 모델은 아니다.

250행 단위 SQL 삽입을 하나의 트랜잭션으로 묶는다. 어느 행이든 잘못되면 이미 적재한 배치도 롤백한다. `ON CONFLICT(food_cd) DO NOTHING`을 사용하므로 재실행은 기존 식품코드를 건너뛰고, 관리자 화면에서 수정한 값을 원본으로 덮어쓰지 않는다. 같은 파일 내부에 중복 코드가 있으면 첫 행을 유지한다. 원본 자체에는 중복이 없다.

Google Sheets에서 내보낸 파일은 worksheet dimension이 `A1`로 지정되어 있지만 실제 데이터는 더 크다. ExcelJS 문서 리더로 실제 셀을 읽어 이 메타데이터 때문에 데이터가 누락되지 않는 것을 원본 파일 테스트로 검증한다. 스트리밍 리더는 ZIP 내부 파일 순서에 따라 메타데이터를 읽기 전에 시트를 처리하는 문제가 있어 사용하지 않았다. 워크북은 메모리에 읽으므로 메모리는 전체 셀 수에 비례한다. 수백만 행으로 확장할 때에는 순서에 의존하지 않는 스트리밍 파서 또는 CSV 적재 경로가 필요하다.
